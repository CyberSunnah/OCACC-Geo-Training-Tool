A tool I made (vibe coded atm) to help me and my colleagues learn local Ottawa Geography, and a project for myself to learn how to code at the same time.

The tool shows a Map of Ottawa and surrounding regions, where the user needs to answer a set of questions, varying by which Mode and Subject they select.

Modes:

Full Eval Practice: This mode is to be used by ACO trainee's to help them prep for the geography portion of their evals. In this mode, the user will be given a location, based on the subject selected, and must 1. Select it's location on the map, and 2. Provide a major intersection in the area using the following format (xxxxxx&xxxxxxx)

Study and Learn: This mode prompts the user to find the location provided on the map by clicking where they believe it is, based on subject selected, but provides the caller with a general area (Including a Major intersection nearby, landmarks or general area)

Multiple Choice Drills: In this mode, the user will be provided a location, based on the subject selected, and then be provided a list of major intersections. The user must correctly select which of the major intersections are in the area of the location in question. (Might remove)

Full Map Matching (name may change): In this more, the user will be provided points of interest / location on the map, identified by a letter inside a circle, they will also be provided a list of locations with a dropdown menu including all the letters seen on the map. They must then correctly match the point of interest / location with the corresponding letter from the dropdown menu.
